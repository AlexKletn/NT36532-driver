# NT36532-driver

[English version](README.md)

[Как участвовать](CONTRIBUTING.ru.md) · [GPL-2.0-only](LICENSE)

Рабочее пространство Rust для драйвера Linux, который будет обслуживать дисплейную и сенсорную части контроллера Novatek NT36532.

| Крейт | Назначение |
| --- | --- |
| `panel-domain` | Планируемая координация работы дисплея |
| `panel-nt36532` | Планируемая логика управления панелью NT36532 по DSI |
| `panel-touch` | Заглушка для обработки касаний NT36532 по SPI |
| `panel-backlight` | Интерфейс управления яркостью |
| `panel-power` | Интерфейс управления питанием панели |
| `adapter-KTZ8866` | Адаптер для обоих интерфейсов. Работу с микросхемой ещё предстоит подключить. |

В `kernel/` лежат заготовки для Kbuild, точки входа модуля и прослойки между C и Rust для DSI.
