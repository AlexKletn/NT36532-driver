# Бесшовная смена частоты в DRM/MSM

[English version](README.md)

[Патч](drm-msm-seamless-refresh.patch) добавляет экспериментальную смену частоты панели на ходу. DRM/MSM обновляет тайминги тракта вывода и вызывает колбэк панели `set_live_refresh`. Возможность включается параметром `msm.spinel_seamless=1`.

В проекте планшета закреплён [Linux v7.3.6](https://github.com/gregkh/linux/tree/v7.3.6), коммит `1a0388846138eda9f6eb4258ff227a223afc2f52`. Аппаратную проверку проводили только на Lenovo TB371FC с адаптированным деревом Linux 7.3.6. В сборке №5 прошли последовательность 120 → 60 → 30 → 144 → 120 Гц с обновлением таймингов на ходу.

Эта редакция применяется к чистому дереву `v7.3.6`. Пропатченное ядро ARM64 и `nt36532.ko` собраны. Проверка символов модуля по `Module.symvers` этого ядра прошла. Аппаратную проверку этой редакции ещё предстоит провести.
